Cloudflare Pages Setup
======================

This site can optionally be deployed via Cloudflare Pages for faster delivery
(especially in the UK) and preview deployments on every pull request.

No code changes are needed — just connect via the Cloudflare dashboard.

Step 1: Go to https://dash.cloudflare.com and log in (free account).
Step 2: Click "Workers & Pages" → "Create application" → "Pages" → "Connect to Git".
Step 3: Select your GitHub repository.
Step 4: Under "Build settings", enter these three values:

  Build command:       cd hugo-site && hugo --minify
  Build output dir:   hugo-site/public
  Root directory:     (leave blank — the repo root)

Step 5: Under "Environment variables", add:

  Variable name:  HUGO_VERSION
  Value:          0.128.0

Step 6: Click "Save and Deploy".

Step 7 (custom domain): Go to your Cloudflare Pages project → Custom domains →
  Add "www.alexandrehefren.com". Cloudflare will guide you to update your DNS
  records. This replaces the GitHub Pages DNS records.

Notes:
- You cannot use both GitHub Pages and Cloudflare Pages simultaneously
  for the same custom domain. Choose one as the live host at a time.
- GitHub Pages (the default) works immediately with the existing CNAME DNS record.
- Cloudflare Pages requires changing the CNAME target from
  alexandrehefren.github.io → <your-project>.pages.dev (Cloudflare handles this).
- Switching back to GitHub Pages is always possible by reverting the DNS record.
